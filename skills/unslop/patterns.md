# Patterns

## Words and phrases

| Tell | Fix |
|------|-----|
| `utilize`, `leverage` | use |
| `facilitate` | help |
| `numerous` | many |
| `in order to` | to |
| `due to the fact that`, `in the event that` | because, if |
| `delve`, `underscore`, `showcase`, `foster`, `garner`, `enhance`, `robust`, `crucial`, `pivotal`, `intricate`, `seamless`, `vibrant`, `enduring`, `tapestry`, `interplay`, `testament` | say the specific thing instead |

- **Puffery:** `pivotal moment`, `testament to`, `evolving landscape`, `setting the stage for`, `deeply rooted`, `stands as`, `serves as`, `boasts`, `a rich tapestry of`.
- **Abstract-metaphor nouns** used to sound deep: `substrate`, `vector`, `locus`, `nexus`, `primitive`, `surface`, `bedrock`, `scaffolding`, `paradigm`, `north star`, `flywheel`, `ratchet`.
- **Vague attribution:** `experts believe`, `studies suggest`, `it is widely regarded`. Name the source or cut it.
- **Chatbot and sycophancy:** `Great question!`, `Certainly!`, `I hope this helps!`, `Let me know if…`. Delete them.
- **Filler:** `It is important to note that`, `It's worth mentioning`, `could potentially`. Delete it or state the point.

## Structures

- **`Not just X, but Y`.** Pick one and say it. `More than X` and `beyond X` are the same tell.
- **Rule of three** everywhere, as in `fast, reliable, and scalable`. Break the symmetry. Two or four items are fine.
- **-ing tails:** `…, highlighting the need for…`, `…, ensuring…`, `…, reflecting…`. Cut the tail or start a new sentence.
- **False ranges:** `from startups to enterprises`, where the span means nothing.
- **Cutoff disclaimers:** `While specific details are limited…`.
- **Generic conclusions:** `The future looks bright`, `Only time will tell`.
- **Passive voice** when the actor is known. Name the actor.
- **Adverbs on weak verbs:** replace "significantly improved" with the number.

## Formatting

- **Em dashes.** Replace each with a period or a comma. This tell is the loudest.
- **Bold on every proper noun or acronym.** Bold only for real emphasis.
- **Title Case Headings.** Use sentence case.
- **Inline-header bullets:** "**Performance:** performance improved" restates itself. Write the sentence.
- **Decorative emojis** in headings and bullets.
- **Colons mid-sentence.** Keep colons for lists and examples.
- **Curly quotes** in plain text or code contexts. Use straight quotes.
