Read this when run-plan tasks repeat one small edit across files. Examples: a one-line fix, a constant change, an added field.

1. Check that each such task stands alone and is the same kind of edit.
2. Merge them into ONE dispatch brief. List every file with the change it gets.
3. Send that brief to a single implementer subagent.
4. Review the combined diff as one unit. The design-doc lane skips this review.

- Do not split such a batch into one subagent per task.
- A task that calls for its own judgment still gets its own dispatch.
- So does a task with its own tests or its own review surface.
